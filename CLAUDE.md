- Set the page to Hebrew and right-to-left: `<html lang="he" dir="rtl">`

- Use `'he-IL'` for date and time formatting.
- Make sure the layout works right-to-left (icons, borders, alignment).
- Keep email addresses, URLs, and code left-to-right where needed.
- Talking to me in chat can stay in whichever language I write in; this rule is about the pages themselves.
