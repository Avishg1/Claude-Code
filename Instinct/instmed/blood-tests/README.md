# דשבורד תוצאות בדיקות דם

> **נתוני הדגמה בדיוניים בלבד - אינם ערכים רפואיים אמיתיים.**
> **המידע להצגה בלבד ואינו מהווה ייעוץ רפואי.** האפליקציה מציגה נתונים בלבד: אין אבחנה, אין פרשנות קלינית ואין המלצות.

## הפעלה

```
cd Instinct/instmed/blood-tests
npm start
```

ואז לפתוח בדפדפן: http://127.0.0.1:5180

נדרש Node.js בלבד. אין `npm install`, אין מסד נתונים, אין חשבונות משתמש. השרת מאזין ל-localhost בלבד ומגיש רשימה סגורה של קבצי האפליקציה.

## מה יש באפליקציה

- **לוח בקרה** — טבלת תוצאות לפי תאריך (ערך, יחידה, טווח ייחוס כפי שהודפס, סימון גבוה/נמוך) וגרף מגמה נפרד לכל בדיקה ולכל יחידת מידה.
- **נתוני הדגמה** (ברירת המחדל) — 20 בדיקות × 5 תאריכים, בדיוניים לגמרי, כולל ערכים חסרים, דוח ללא טווח ושינויי טווח.
- **ייבוא PDF** — בחירת קבצים או גרירה. הקובץ נקרא בדפדפן בלבד, מוצג מסך בדיקה עם שורת המקור לצד כל שורה, ורק לאחר אישור השורות נשמרות.
- נתונים מיובאים מוצגים בנפרד מנתוני ההדגמה (מתג "מקור הנתונים"), מסומנים "PDF · שם הקובץ", וניתן למחוק קובץ בודד או את הכול, ולייצא ידנית ל-JSON.

## כללי הנתונים

- סימון גבוה/נמוך מחושב **רק** מול טווח הייחוס שבאותו דוח. אין טווח → אין סימון, ומוצג "טווח ייחוס לא ידוע".
- טווח לא מספרי (למשל "שלילי") או ערך לא מספרי (למשל `<0.5`) → אין סימון.
- גבולות: `a–b` כולל את הקצוות; `< x` / `> x` לא כוללים; `≤` / `עד` כוללים.
- ערך חסר מוצג "חסר" — אף פעם לא מושלם, מנוחש או מועתק מתאריך אחר.
- אין המרת יחידות. אותה בדיקה ביחידות שונות מוצגת בגרפים נפרדים.
- בייבוא: שם, יחידה וטווח נשמרים כפי שהודפסו. מה שלא נקרא בוודאות נשאר ריק ומסומן "חסר" או "לא ברור".

## פרטיות

- הכול רץ מקומית. ספריית pdf.js מצורפת בתיקייה `vendor/pdfjs` (ללא CDN, ללא גופנים חיצוניים, ללא WebAssembly, ללא טלמטריה). מדיניות CSP חוסמת כל פנייה לכתובת חיצונית.
- ה-worker של pdf.js נטען עם פתיחת האפליקציה, כך שבזמן ייבוא קובץ אין אף בקשת רשת.
- קובץ ה-PDF עצמו אינו נשמר. נשמרות רק השורות שאושרו, ב-localStorage של הדפדפן במחשב זה.
- אין זיהוי תווים (OCR). קובץ סרוק ללא שכבת טקסט נדחה עם הודעה, ודבר אינו מיובא.
- התיקייה `real-pdfs/` מיועדת לקבצים אמיתיים במחשב שלך ומוחרגת ב-`.gitignore`, וכך גם קובצי ייצוא (`imported-blood-tests-*.json`). אין לבצע commit לקבצים אמיתיים או לנתונים מיובאים.

## בדיקות

כל קובצי הבדיקה בתיקייה `test-pdfs/` **בדיוניים** ונוצרו על ידי הסקריפט:

```
npm run make-test-pdfs   # יצירת קובצי PDF בדיוניים (דורש Edge או Chrome)
npm run check            # בדיקה מקצה לקצה בדפדפן אמיתי (59 בדיקות)
```

`npm run check` מפעיל את השרת ודפדפן ללא ממשק, מייבא כל קובץ בדיקה, משווה כל ערך/יחידה/טווח ל-`test-pdfs/expected.json`, מוודא שאין בקשות רשת בזמן הייבוא, ובודק את כללי התצוגה, המחיקה והמובייל.

## מגבלות ידועות של מנתח ה-PDF

- מיועד לדוחות בצורת טבלה עם שורת כותרת (בעברית או באנגלית). בלי כותרת מזוהה, השורות מסווגות לפי תוכן — פחות אמין, ולכן מסך הבדיקה חובה.
- תאריך בפורמט `dd/mm/yyyy` או `dd.mm.yyyy` נקרא כיום/חודש/שנה (כמקובל בדוחות בישראל). הטקסט כפי שהודפס מוצג לבדיקה, וניתן לתקן.
- בחלק מקובצי PDF בעברית, טקסט ניטרלי (יחידות כמו `10^3/µL`) כבר שמור בסדר חזותי הפוך בתוך הקובץ. במקרה כזה הטקסט יוצג כפי שהוא בקובץ — יש לתקן במסך הבדיקה.
- הסימן µ עשוי להישמר בקובץ כאות היוונית μ (נראות זהה). הטקסט נשמר כפי שחולץ.
