# ניהול תקלות – ועד הבית

אפליקציית ווב מקומית לניהול תקלות ותחזוקה בבניין מגורים: רישום כל תקלה, מעקב מהדיווח ועד הפתרון, תיאום מול בעלי מקצוע חיצוניים ושמירת היסטוריה מסודרת.

## איך פותחים

1. פותחים את הקובץ `index.html` בדפדפן (לחיצה כפולה). מומלץ Chrome, Edge או Firefox בגרסה עדכנית.
2. אין צורך בהתקנה, בשרת או בחיבור לאינטרנט.
3. בפתיחה הראשונה נטענות 10 קריאות לדוגמה, כדי שאפשר יהיה להתרשם מהמערכת מיד.

> **התחלה מאפס:** בלוח הבקרה או במסך ההגדרות לוחצים על **"מחיקת כל הנתונים"**. הפעולה מוחקת את כל הקריאות והקבצים, ורשימות ההגדרות (חברי ועד, ספקים, קטגוריות) נשמרות.

## היכן נשמרים הנתונים

- **קריאות והגדרות:** ב-`localStorage` של הדפדפן.
- **תמונות וסרטונים:** ב-IndexedDB של הדפדפן.
- הנתונים שמורים **רק בדפדפן ובמחשב שבהם עובדים**. מומלץ להוריד גיבוי מדי פעם (הגדרות ← "הורדת קובץ גיבוי"). הגיבוי הוא קובץ JSON שכולל גם את הקבצים המצורפים.
- ניקוי נתוני הגלישה בדפדפן מוחק גם את נתוני המערכת.

## מסכים עיקריים

| מסך | מה יש בו |
|---|---|
| **לוח בקרה** | כרטיסי סיכום (פתוחות, דחופות, בטיפול חיצוני, באיחור, נפתרו החודש). לחיצה על כרטיס מסננת את הרשימה. טבלת קריאות עם מיון לפי כל עמודה, סינון, חיפוש חופשי (כולל בתוכן העדכונים) וייצוא ל-Excel. |
| **קריאה** | כל פרטי הקריאה, ציר זמן של עדכונים (החדש ראשון), הוספת עדכון עם תמונות או סרטונים ושינוי סטטוס, טיפול חיצוני עם כפתור חיוג, היסטוריית סטטוסים, הדפסת סיכום וטקסט מוכן לוואטסאפ. |
| **קריאה חדשה / עריכה** | טופס מלא. בחירת ספק מספר הספקים ממלאת את פרטיו אוטומטית. אם כבר דווחו בעבר תקלות דומות באותו מיקום, מוצגת התראה עם קישורים אליהן. |
| **סטטיסטיקה** | קריאות לפי סטטוס, לפי קטגוריה, לפי עדיפות, קריאות שנפתחו בכל חודש וממוצע הימים עד פתרון. |
| **הגדרות** | עריכת חברי הוועד, ספר הספקים, הקטגוריות, הקומות והאזורים. גיבוי, שחזור, טעינת נתוני הדגמה ומחיקת כל הנתונים. |

## סימוני מועדים

כשנפתחה תקלה אצל גורם חיצוני והוזן "מתי אמור להגיע":

- 🔴 **באיחור:** המועד עבר והתקלה עדיין פתוחה.
- 🟠 **מתקרב:** המועד חל בתוך יומיים או פחות.

הסימון מופיע בלוח הבקרה, ברשימת הקריאות ובתוך הקריאה עצמה.

## קיצורי מקלדת ונגישות

- <kbd>N</kbd>: פתיחת קריאה חדשה. <kbd>/</kbd>: מעבר לחיפוש. <kbd>Esc</kbd>: סגירת חלון.
- כפתור הנגישות בפינת המסך מאפשר הגדלת טקסט, ניגודיות גבוהה, הדגשת קישורים, גופן קריא, ריווח טקסט, עצירת אנימציות וסמן עכבר גדול. ההגדרות נשמרות.

## קבצים

- `index.html`: מבנה הדף.
- `styles.css`: עיצוב (ערכת צבעים כחול כהה, RTL, רספונסיבי, הדפסה).
- `app.js`: כל הלוגיקה: נתונים, תצוגות, ייצוא, גיבוי ונגישות.

## הערות

- סוגי הקבצים הנתמכים לצירוף: jpg, png, gif, webp, mp4, mov, webm, עד 200MB לקובץ. קבצי mov מתנגנים רק בדפדפנים שתומכים בפורמט (בעיקר Safari).
- קובץ הייצוא ל-Excel הוא CSV בקידוד UTF-8, ולכן העברית נפתחת ב-Excel בצורה תקינה.
- ההעתקה ללוח (טקסט לוואטסאפ) עשויה להיחסם בחלק מהדפדפנים כשהקובץ נפתח מהדיסק. במקרה כזה הטקסט מוצג בחלון ואפשר להעתיק אותו ידנית.
